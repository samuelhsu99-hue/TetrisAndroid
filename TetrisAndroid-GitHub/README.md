# Android 俄罗斯方块

不需要 Android Studio。上传到 GitHub 后，GitHub Actions 会自动编译 APK。

## 下载 APK
1. 打开仓库的 **Actions**。
2. 点左侧 **自动生成俄罗斯方块 APK**。
3. 打开最新一次绿色成功的运行。
4. 页面底部 **Artifacts** 下载 **Tetris-APK**。
5. 解压后得到 `app-debug.apk`，传到 Android 手机安装。

如果 GitHub 要求允许 Actions，请在仓库 Settings > Actions > General 中允许 Actions。
